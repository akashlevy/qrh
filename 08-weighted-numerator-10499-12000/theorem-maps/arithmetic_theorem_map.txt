Arithmetic formalization: theorem-to-manuscript map
==================================================

All names below are in namespace WeightedQRH.  The three arithmetic
modules import Mathlib only (directly or through each other).  They do
not import any QRH theorem, analytic claim, feedback overlay, or rejected
improvement.  The Python generator proposes explicit polynomial
identities; Lean's ring and positivity tactics generate proof terms
checked by the kernel.  No native_decide, sorry, axiom, or certificate
sign oracle is used in these modules.

Parameters.lean
---------------
theta,ell,b,lx,ly,h,kappa : eq:new-geometry and thm:weighted-main.
endpointMargin : 1/10000, lem:new-certificate.
rowExtension : 1/1000000, a concrete valid extension replacing the
               manuscript's sufficiently small zeta.
theta_eq : B=11/12-ell/4.
theta_lt_public : exact numerical comparison with the displayed public
                  rational benchmark, not a verification of that
                  benchmark's external proof status.
kappa_admissible : (1+kappa)/2=7/8.
length_sum,length_difference,row_endpoint : all geometry identities.
signal_low : eq:new-low equality C(B)=lx/2+b/12.
signal_slope : slope-one difference used by continuation.
gram_domination,x_rescaled_pos,y_rescaled_pos,row_rescaled_pos : the
              low estimate's strict scale hypotheses.
low_rescaled_identity,low_rescaled_tuple : M'+ell'-1=-3v and the
              full real-v tuple majorant, not only endpoint sampling.
row_count_supply,row_extension_supply : selected witness prime supply.
numerator_short,numerator_supply,numerator_supply_all,numerator_range :
              eq:new-capacity-supply, including every d in[1/2,h].
extended_row_count_supply,extended_numerator_short,extended_h_lt_one,
extended_row_supply : corresponding strict gates at h+rowExtension.
small_row_margin : the certified absolute small-row saving.
principal_w_margin,principal_z_margin : positive principal residue gaps.
principal_local_exponents,principal_euler_defects : the fixed endpoint
              inequalities for the second Euler region.
euler_tail_capacity_gap : rho-q/(6kappa)>=5delta/36 coefficient identity.
low_barrier_identity : exact displayed dual identity in the GRH-barrier
              section of weighted_numerator_proof.tex.
low_barrier : stated low/energy sufficient exponents imply B>=13/15.
physical_low_barrier : same scoped barrier including g and x/y lengths.
              These are not claims about actual zeros or other methods.

CertificateBernstein.lean
-------------------------
countD,countP,countDen,countNum,rowCount : D_x,P_x,J,RJ,R in Available
              row counts; the count's analytic validity is not assumed
              or proved in this arithmetic module.
countDen_pos : J>0 on the full real rectangle[0,3/4]x[0,1/2].
oldCert,weightedCert : exact numerators -J(E(h)+1/10000).
old_identity_0,weighted_identity_0...8 (private) : explicit positive
              unnormalised Bernstein expansions on the ten JSON leaves.
old_leaf_0,weighted_leaf_0...8 : nonnegativity on each leaf.
oldCert_nonneg,weightedCert_nonneg : full real rectangles, with coverage
              proved by an explicit sequence of order cases.

ExponentCertificate.lean
-------------------------
genericOldExponent : eq:old-high-new-geometry with arbitrary q,R.
oldExponent : eq:old-high-new-geometry using q=delta*x and rowCount.
weightedExponent : eq:weighted-high with the prime-capacity saving.
rowCount_formula, rowCount_lower,rowCount_upper : algebraic dictionary
              and 1-delta<=R<=1 on the full real rectangle.
oldCert_identity,weightedCert_identity : exact links from the
              polynomial certificates to the displayed rational E.
old_endpoint_bound : all delta in[0,1/3], x in[0,1/2], E_old(h)<=-1/10000.
weighted_endpoint_bound : all delta in[1/3,3/4], x in[0,1/2],
              E_weighted(h)<=-1/10000.
old_frequency_slope_pos,weighted_frequency_slope_pos : positive d slopes.
old_frequency_slope_le_two,weighted_frequency_slope_le_two : upper bound2.
old_row_difference,weighted_row_difference : exact affine d dependence.
old_moderate_bound,weighted_moderate_bound : the same1/10000 bounds for
              all d<=h; analytic applicability still needs d>=1/2.
old_extended_bound,weighted_extended_bound : all d<=h+1/1000000 have
              margin1/20000 on their respective delta rectangles.
binwise_uniform_bound : the contour branch is selected from delta alone,
              outside the universal quantifier over amplitude x.
floor_endpoint,floor_row_bound : the floor-bin exponent for every d<=h.
intermediate_endpoint_bound,intermediate_row_bound : the unselected
              exponent for every delta in[1/50,3/4] and d<=1/2.

Build and audit
----------------
Use lean_environment.json with the installed Lean4.34.1 executable.
Compile order: Parameters, CertificateBernstein, ExponentCertificate.
CertificateAxioms.lean prints proof dependencies of the main results.
Build logs are Parameters.build.log, CertificateBernstein.build.log,
ExponentCertificate.build.log, and CertificateAxioms.log.
Successful compilation proves these arithmetic claims; it does not by
itself instantiate an analytic physical-probe contract or prove QRH.

Benchmark update (2026-10-09): Parameters.publicBenchmark and theta_lt_public
compare against the earlier reported public rational. CertificateBenchmark.lean
adds theta_lt_public_cubic_lower, proving theta < 8749570194/10^10, the lower
endpoint of the tighter public cubic-root bracket; it also proves the comparison

These are arithmetic comparisons only: neither theorem assumes or certifies
